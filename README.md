# 🛠️ MalikLang UI Studio v1.0

Welcome to **MalikLang UI Studio**, a completely private, personal, and lightweight custom programming language ecosystem engineered from scratch using C++ and the Windows API. 

This project features a custom language interpreter integrated directly into a native desktop Graphical User Interface (GUI), ensuring efficient execution and a minimal hardware footprint perfect for standard desktop PCs.

## ✨ Key Features

* **🔒 100% Personal Syntax:** A proprietary tokenization and parsing logic uniquely customized by the author.
* **🎨 Native Windows GUI:** Built utilizing low-level Win32 APIs (`<windows.h>`) for a fast, zero-bloat graphical environment.
* **⚡ Logic & UI Compiler:** Seamlessly bridges the gap between language execution logic and desktop window rendering.
* **☁️ Cloud-Powered CI/CD:** Integrated with automated GitHub Actions workflows to compile binaries (`.exe`) instantly on the cloud without needing local setups like MinGW.
* **📉 Resource-Efficient:** Optimized for reliable performance on low-spec systems (such as Dell OptiPlex 960 hardware configurations).

## 🚀 How It Works

1.  **Code Input:** Write your custom language scripts directly inside the built-in IDE code panel.
2.  **Lexical Execution:** The custom C++ core backend tokenizes and evaluates the logic on-the-fly.
3.  **Instant Output:** View output immediately within the integrated reading console.
